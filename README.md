# Pokédex

Aplicação web desenvolvida em React como projeto final da disciplina **Frameworks Web I**.

A aplicação utiliza a **PokéAPI** para consultar informações sobre os Pokémon, permitindo pesquisar, filtrar, navegar entre páginas e visualizar detalhes de cada Pokémon.

## Funcionalidades

* Pesquisa de Pokémon por nome
* Pesquisa utilizando a tecla Enter
* Filtro por tipo
* Paginação dos Pokémon
* Cards com informações dos Pokémon
* Página de detalhes
* Acesso a um Pokémon aleatório
* Exibição de estatísticas
* Exibição de habilidades, altura e peso
* Indicador de carregamento
* Tratamento de erros
* Interface responsiva
* Interface desenvolvida com Material UI

## Tecnologias utilizadas

* React
* JavaScript
* Vite
* Axios
* React Router DOM
* Material UI
* PokéAPI

## API utilizada

Os dados dos Pokémon são obtidos através da:

**PokéAPI**

https://pokeapi.co/

##  Como executar o projeto

### 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entrar na pasta do projeto

```bash
cd trabalho-frameworks-web
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

```bash
npm run dev
```

Após executar o comando, acesse o endereço informado pelo Vite no terminal.
